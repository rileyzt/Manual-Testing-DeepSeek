# 🧪 DeepSeekR1 Manual Testing (Standardized QA Documentation)

Welcome to the DeepSeekR1 Manual Testing Project!  
This project showcases a complete **manual testing case study** of the **DeepSeekR1 AI Chatbot**, modeled on real-world QA industry standards (IEEE 829). It highlights core manual testing skills used in functional, UI/UX, and security testing.

---

## ✅ Project Objective

To perform structured **manual test case design and execution** for the DeepSeekR1 chatbot — covering critical areas like:
- Chat logic & factual accuracy
- UI/UX consistency
- Ethical filtering
- Context memory
- Performance (response time)
- Security (input validation, neutrality)

## 🧾 Test Case Format (IEEE 829 Standard)

| Field | Description |
|-------|-------------|
| Test Case ID | Unique identifier like `TC001` |
| Title | Descriptive name of the test case |
| Module | Feature or functionality being tested |
| Preconditions | Conditions before executing the test |
| Test Steps | Step-by-step instructions |
| Test Data | Inputs used for the test |
| Expected Result | Correct system behavior |
| Actual Result | Outcome of the test |
| Status | Pass/Fail |
| Severity | Business impact of the issue |
| Priority | Fix urgency from a QA/dev perspective |
